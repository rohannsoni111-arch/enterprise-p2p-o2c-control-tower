# Architecture & Technical Design Specifications

This directory contains formal enterprise documentation for the **Enterprise Procure-to-Pay (P2P) & Order-to-Cash (O2C) Digital Control Tower**:

- `Functional_Specification_Document.md`: Comprehensive enterprise FSD covering MM/SD processes, business rules, acceptance criteria, and stakeholder matrix.
- `Architecture.md`: Layered system architecture, request flows, and security design.
- `Database_Design.md`: 3NF ER diagrams, relational table structures, foreign keys, indexes, and constraints.
- `Business_Rules.md`: Formal business rule catalog (RULE-001 through RULE-010+), variance formulas, and remediation actions.
- `API.md`: REST API endpoint specifications with sample requests, query params, and structured error codes.
- `Interview_Preparation.md`: Junior Functional Consultant interview guide with 25+ real-world Q&As grounded in the codebase.
- `Resume_Bullets.md`: High-impact, verified resume bullet points highlighting SAP MM/SD functional design.
- `GitHub_Description.md`: Professional repository metadata and project summary.
- `bpmn/`: BPMN 2.0 process flow diagrams for As-Is and To-Be P2P and O2C workflows.
